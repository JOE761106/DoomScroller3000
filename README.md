what it does:  
  -scrolls yt shorts  
  -gets yt short  
  -sends to discord
instructions:
  1.create a folder called playwright_chrome on your C:
    inside that folder create a folder called User Data
  2.choose a google profile you wish running the bot on e.g Profile 2
  3.open the profile you wish running the bot on 
  4.type in link search bar chrome://version/
  5.search for text that says:Profile Path
  6.go to that file path the text said e.g :\Users\Joe\AppData\Local\Google\Chrome\User Data\Profile 2
  7.copy the folder of the profile you chose in this case its Profile 2
  8.paste the folder in the file path we created earlier in steps C:\playwright_chrome\User Data\
  9.run the bot
